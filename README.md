# Real-Time Collaborative Editor System-Design
Requirements

- Docker & Docker Compose

Build & Start:
1. Clone the repository: 
   ```bash
   git clone 
   ```
2. Navigate to the project directory:
   ```bash
   cd RTCE-SystemDesign
   ```
3. Run with Docker Compose:
   ```bash
   Docker Compose build
   Docker Compose up -d
   ```
